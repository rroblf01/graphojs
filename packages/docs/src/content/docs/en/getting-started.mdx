GraphoJS is an open-source (MIT), drop-in alternative to GoJS. Most
applications migrate by changing **just the import line**.

## Installation

```bash
npm install graphojs
# or, for the GoJS-compatible namespace:
import * as go from 'graphojs/go';
```

Just want to try it without setting up a project? You can load GraphoJS
directly from a CDN, no `npm install` or bundler required — see [Using
GraphoJS without npm (CDN)](/en/guide/cdn/).

## Your first diagram

The playground below shows a diagram with three nodes and two links. Edit

## What happened

1. `go.Diagram('graphojs-root')` creates the diagram inside the element with that id.
2. `diagram.nodeTemplate` defines how each node is drawn (a shape + a label).
3. `diagram.model` is a `GraphLinksModel` with `nodeDataArray` and `linkDataArray`.
4. The engine takes care of rendering, events, and interactions.
