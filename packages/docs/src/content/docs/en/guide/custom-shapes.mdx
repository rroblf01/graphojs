When none of the [predefined shapes](/en/guide/shapes/) fit,
`Shape.geometryString` accepts a full SVG path — it automatically scales to
the `Shape`'s actual size (no need to calculate exact pixel coordinates).

<Playground code={customShapesExample} height={480} />

## Supported commands

`M` `L` `H` `V` `C` `S` `Q` `T` `A` `Z` — uppercase (absolute coordinates)
or lowercase (relative), just like in SVG. Implicit command repetition is
also supported (`L10,0 20,10 30,0` is equivalent to
`L10,0 L20,10 L30,0`).

```js
$(go.Shape, { geometryString: 'M50,0 L100,80 L0,80 Z' }); // triangle
```

Or bind it from the model, as in the playground:

```js
$(go.Shape, new go.Binding('geometryString', 'geometry'));
// data: { geometry: 'M0,0 L60,0 L100,40 L60,80 L0,80 L40,40 Z' }
```
