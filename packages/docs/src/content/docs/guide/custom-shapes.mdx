Cuando ninguna de las [figuras predefinidas](/guide/shapes/) sirve,
`Shape.geometryString` acepta un path SVG completo — se ajusta
automáticamente al tamaño real del `Shape` (no hace falta calcular
coordenadas exactas de píxel).

<Playground code={customShapesExample} height={480} />

## Comandos soportados

`M` `L` `H` `V` `C` `S` `Q` `T` `A` `Z` — en mayúscula (coordenadas
absolutas) o minúscula (relativas), igual que en SVG. También se admite la
repetición implícita de comandos (`L10,0 20,10 30,0` equivale a
`L10,0 L20,10 L30,0`).

```js
$(go.Shape, { geometryString: 'M50,0 L100,80 L0,80 Z' }); // triángulo
```

O enlázalo desde el modelo, como en el playground:

```js
$(go.Shape, new go.Binding('geometryString', 'geometry'));
// data: { geometry: 'M0,0 L60,0 L100,40 L60,80 L0,80 L40,40 Z' }
```
