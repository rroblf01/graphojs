Puedes añadir nodos al diagrama dinámicamente, ya sea arrastrando desde una
palette o programáticamente.

<Playground code={dragDropExample} height={480} />

## Añadir nodos programáticamente

```js
model.addNodeData({ key: 5, label: 'Nuevo', x: 150, y: 100 });
```

## Palette y drop

`go.Palette` muestra templates arrastrables. Al soltarlos sobre el diagrama se
crea un nodo nuevo. El patrón completo está en `e2e/fixtures/palette.html`.

## Reaccionar a los cambios

`diagram.addDiagramListener('PartAdded', ...)` se dispara cuando se añade un
nodo. Prueba a pulsar **+ Añadir nodo** varias veces.
