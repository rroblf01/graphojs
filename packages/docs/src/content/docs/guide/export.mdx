<Playground code={exportExample} height={460} />

## API de export

- `diagram.makeImage({ scale, background, padding })` → `HTMLCanvasElement`
- `diagram.makeImageData({ scale })` → data URL de PNG
- `diagram.makeSvg()` → `SVGElement`
- `diagram.print()` → imprime el diagrama

El playground de arriba expone `__exportImage`, `__exportSvg` y `__print`
para probarlos desde la consola del navegador.
