GraphoJS incluye ~80 figuras de Shape. El `figure` de un `Shape` determina su
forma, y puede venir del modelo con un binding.

<Playground code={shapesExample} height={500} />

## Figuras disponibles

`Rectangle`, `RoundedRectangle`, `Ellipse`, `Diamond`, `Triangle`, `Hexagon`,
`Star`, `Cross`, `Cylinder`, `Document`, `Parallelogram`, y muchas más.

### UML / BPMN / anotaciones

- `component` — componente UML (caja con dos muescas de conector en el borde izquierdo).
- `gatewayExclusive` — gateway exclusivo BPMN (diamante con X).
- `gatewayParallel` — gateway paralelo BPMN (diamante con +).
- `callout` — bocadillo de comentario con cola.
- `bracket` — corchete de anotación de flowchart, abierto a la izquierda.
- `flag` — bandera/banderín, útil para hitos (ver la guía de [Gantt](/guide/gantt/)).
- `chevron` — flecha/cinta simple (distinta de `doubleChevron`).
- `tape` — símbolo de cinta de papel ANSI (bordes ondulados).
- `shield` — escudo de seguridad/protección.
- `bolt` — rayo/símbolo de disparador.

## Cambiar la forma dinámicamente

```js
$(go.Shape, 'Rectangle', {}, new go.Binding('figure', 'figure'))
```

El `figure` se lee de `data.figure`, así que cada nodo puede tener una forma
distinta. Prueba a cambiar `figure` o `fill` en los datos.
