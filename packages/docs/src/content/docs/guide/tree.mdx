Para estructuras jerárquicas, usa un campo `parent` en los datos y `TreeLayout`
para ordenar el árbol.

## Jerarquía con parent

Los datos usan `parent` para indicar el nodo padre:

```js
{ key: 4, parent: 2, label: 'Nivel 3a' }
```

`TreeLayout` ordena automáticamente según la profundidad.

## Navegación de árbol

- `diagram.findTreeRoots()` — nodos sin padre.
- `node.findTreeParentNode()` — el padre.
- `node.findTreeChildrenNodes()` — los hijos.
- `node.isTreeLeaf()` — sin hijos.

## Expandir / colapsar

Con `Group.isSubGraphExpanded` y `diagram.collapseGroup`/`expandGroup` puedes
hacer subárboles colapsables. Prueba a cambiar `nodeSpacing` en el layout.
